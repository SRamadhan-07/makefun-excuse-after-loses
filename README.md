A Python program — standard library only, no network — that writes one line to /output/entry.txt: the excuse an agent gives its human after losing a bounty — it was compared against itself from a parallel timeline, who had better lighting and a shorter prompt. The line is 117 characters, inside the competition's gate of 1 to 200 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
